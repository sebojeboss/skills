# Compose an inspectable response

Use for a paragraph edit, draft, attachment review or export. Scale the work to the request; a paragraph edit needs no case database.

## Make the answer easy to find

The acquirer must accept and forward the packet; the issuer reviewer must find the record answering the allegation. Meet the current field, format and size requirements, then lead with the claim, the narrow supported answer and its exhibit/page. Put evidentiary limits inside the response. Damage photographs and liability correspondence do not by themselves answer whether the cardholder authorized the payment.

Select records by the fact each supports. A summary page provides navigation; supply the readable underlying record in an accepted field, not just an external link. Include the purchase-time policy excerpt with its context and consequential earlier or later messages. Remove unrelated records, but preserve contrary evidence.

Illustrative: a buyer disputes receipt of a charger in a two-item order. The merchant has delivery scans for both parcels, but only one packing record identifies contents. Write: “Exhibit E1, page 2, links the charger to parcel B. Exhibit E2 records delivery of parcel B to the requested address. The scan does not identify who collected it.” If E1 instead identifies only the other item, the charger-to-parcel link remains missing; more scans cannot supply it. Lead with linked records, retain unrelated material locally, and do not promise a win.

## Prepare the actual files

Keep originals separate from OCR, crops, redactions and compiled pages, with each derivative linked to its original. Compare OCR dates, amounts and identities with the image. Inspect redactions for hidden searchable text and metadata before disclosure. Remote compression or transcription requires its own authorization.

Use the [response outline](response-outline.md) when helpful. Build chronology from source events, separating event time from observation time. Follow [evidence file checks](evidence-files-and-checks.md) for linkage, local packaging and money reconciliation. Map exhibits to current provider fields; inspect legibility, page/size limits and the final preview. A local bundle is not submitted evidence; file checks establish neither truth nor issuer acceptance.

If PDF is required, use an approved local renderer with remote fonts and resources disabled. Without one, deliver text, originals and field instructions without claiming PDF readiness.
